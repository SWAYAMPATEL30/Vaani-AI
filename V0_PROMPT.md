# 🎨 V0 Prompt for Voice Calling Agent Dashboard

## Copy this entire prompt to v0.dev:

---

Create a modern, professional dashboard web application for a Voice AI Calling Agent system. The app should be built with Next.js 14, TypeScript, Tailwind CSS, and shadcn/ui components.

## Core Features:

### 1. Dashboard Overview Page
- Real-time call statistics cards showing:
  - Total calls today
  - Active calls
  - Average call duration
  - Success rate percentage
- Recent calls list with status badges (ringing, in-progress, completed, failed)
- Live activity feed showing incoming calls in real-time
- Quick action buttons: "Make Test Call", "View Analytics", "Settings"

### 2. Calls Management Page
- Data table with all calls showing:
  - Call ID
  - From/To phone numbers
  - Status (with color-coded badges)
  - Start time and duration
  - Actions: View Details, View Transcript, Download Recording
- Filtering by date range, status, phone number
- Search functionality
- Pagination
- Export to CSV/Excel button

### 3. Call Details & Transcripts Page
- Call information card (Call SID, numbers, duration, timestamps)
- Conversation transcript viewer showing:
  - User messages (left-aligned, blue)
  - AI agent responses (right-aligned, green)
  - Timestamps for each message
  - Speaker labels
- Download transcript button (JSON/CSV)
- Audio playback if available
- Conversation summary generated by AI

### 4. Analytics Page
- Charts and graphs:
  - Calls per day/week/month (line chart)
  - Call duration distribution (bar chart)
  - Status breakdown (pie chart)
  - Peak hours heatmap
- Key metrics cards
- Export analytics report

### 5. Settings Page
- API configuration display (masked keys)
- Service status indicators (AssemblyAI, Groq, ElevenLabs, Twilio)
- Webhook URL configuration
- Test connection buttons for each service
- System logs viewer

## API Integration:

The backend API is available at: `http://localhost:5000` (or deployed URL)

### API Endpoints to integrate:

1. `GET /health` - Health check and service status
2. `GET /api/calls` - Get all calls (returns array of call objects)
3. `GET /api/calls/<call_sid>/transcripts` - Get transcripts for a call
4. `POST /api/process-audio` - Process audio file (for testing)

### API Response Examples:

**GET /api/calls:**
```json
{
  "calls": [
    {
      "id": 1,
      "call_sid": "CA123...",
      "from_number": "++91XXXXXXXXXX",
      "to_number": "+1XXXXXXXXXX",
      "status": "completed",
      "start_time": "2026-01-16T10:30:00Z",
      "end_time": "2026-01-16T10:35:00Z",
      "duration": 300
    }
  ]
}
```

**GET /api/calls/<call_sid>/transcripts:**
```json
{
  "call_sid": "CA123...",
  "transcripts": [
    {
      "text": "Hello, how are you?",
      "is_final": "true",
      "timestamp": "2026-01-16T10:30:15Z",
      "speaker": "user"
    },
    {
      "text": "I'm doing great! How can I help you today?",
      "is_final": "true",
      "timestamp": "2026-01-16T10:30:20Z",
      "speaker": "agent"
    }
  ]
}
```

## Design Requirements:

- **Color Scheme**: Modern dark/light theme toggle
  - Primary: Blue (#3B82F6)
  - Success: Green (#10B981)
  - Warning: Yellow (#F59E0B)
  - Error: Red (#EF4444)
- **Typography**: Clean, readable fonts (Inter or system fonts)
- **Layout**: Responsive design, works on mobile/tablet/desktop
- **Components**: Use shadcn/ui components (Button, Card, Table, Badge, Dialog, etc.)
- **Icons**: Use Lucide React icons
- **Animations**: Smooth transitions, loading states, skeleton loaders

## Key Components Needed:

1. **CallCard** - Displays call information in a card format
2. **TranscriptViewer** - Chat-like interface for conversation transcripts
3. **StatsCard** - Reusable card for displaying statistics
4. **StatusBadge** - Color-coded status indicators
5. **DataTable** - Sortable, filterable table for calls
6. **Charts** - Using recharts or similar for analytics
7. **RealTimeIndicator** - Shows live call status
8. **ExportButton** - Downloads data as CSV/Excel

## Additional Features:

- **Real-time Updates**: Use polling or WebSocket to refresh call data every 5 seconds
- **Toast Notifications**: Show success/error messages
- **Loading States**: Skeleton loaders while data loads
- **Error Handling**: Graceful error messages with retry options
- **Empty States**: Friendly messages when no data available
- **Date Range Picker**: For filtering calls by date
- **Search Bar**: Quick search across calls

## Technical Stack:

- **Framework**: Next.js 14 (App Router)
- **Language**: TypeScript
- **Styling**: Tailwind CSS
- **Components**: shadcn/ui
- **Data Fetching**: React Query / SWR
- **Charts**: Recharts
- **Date Handling**: date-fns
- **HTTP Client**: Axios or fetch
- **State Management**: React hooks / Zustand (if needed)

## Example Page Structure:

```
/dashboard (overview)
/calls (list all calls)
/calls/[callSid] (call details with transcript)
/analytics (charts and metrics)
/settings (configuration)
```

## API Base URL:

Set as environment variable: `NEXT_PUBLIC_API_URL=http://localhost:5000`

## Special Requirements:

1. Handle CORS properly (backend has CORS enabled)
2. Format phone numbers nicely (+1 (919) 702-5605)
3. Format timestamps in user's timezone
4. Show call duration in readable format (5m 30s)
5. Handle pagination for large datasets
6. Implement proper error boundaries
7. Add loading states for all async operations
8. Make it production-ready with proper error handling

## Visual Style:

- Clean, modern, professional look
- Similar to Vercel dashboard or Stripe dashboard
- Card-based layout
- Good use of whitespace
- Consistent spacing and typography
- Accessible (WCAG compliant)

## Additional Context:

This is a Voice AI Calling Agent that:
- Receives calls via Twilio
- Transcribes speech using AssemblyAI
- Generates responses using Groq LLM
- Converts text to speech using ElevenLabs
- Stores all data in PostgreSQL database

The dashboard should help users:
- Monitor calls in real-time
- Review conversation transcripts
- Analyze call metrics
- Manage system configuration
- Export data for reporting

Make it intuitive, fast, and beautiful!
