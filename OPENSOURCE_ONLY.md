# Open-Source Only Configuration

## ✅ All Twilio Say Removed

The system now uses **ONLY open-source models** for STT and TTS:

### STT (Speech-to-Text)
- **PRIMARY**: Local Whisper (`openai-whisper`)
- **FALLBACK 1**: OpenAI Whisper API
- **FALLBACK 2**: AssemblyAI (uses Whisper)

### TTS (Text-to-Speech)
- **PRIMARY**: Veena TTS (`maya-research/veena-tts`)
- **FALLBACK 1**: Facebook MMS TTS Hindi (`facebook/mms-tts-hin`)
- **FALLBACK 2**: Hugging Face Inference API

### Twilio Usage
- **ONLY for call service** (Record, Play, Gather, Hangup)
- **NO Twilio Say** - all speech is from open-source TTS

## Testing Flow

1. **Greeting**: Uses Veena/MMS TTS to generate Hindi audio → Twilio `<Play>`
2. **User Speech**: Recorded by Twilio → Processed by Whisper STT
3. **AI Response**: Generated by Groq LLM in Hindi
4. **TTS**: Converted to speech by Veena/MMS TTS → Twilio `<Play>`
5. **Loop**: Continues with Record → Whisper → Groq → TTS → Play

## If TTS Fails

- System will proceed with silent recording (for STT testing)
- No fallback to Twilio Say
- This allows you to test if STT is working even if TTS fails
